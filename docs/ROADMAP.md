# Feuille de route CATÉNA

1. **v0.2.0 — PWA autonome (cette livraison)** : stockage local, mode hors ligne, installation Android/iOS, publication GitHub Pages, suivi du numéro de version. Données fictives uniquement.
2. **v0.3.x — Éditeur de plan** : import contrôlé, symboles, glisser-déposer mobile, validations et versions du plan, affectations testées.
3. **v0.4.x — Parcours terrain** : interactions en 2–3 clics, photos, anomalies, suivi des déclarations, contraintes de connectivité, tests d’utilisabilité.
4. **v0.5.x — Recollement** : revue indépendante, versions du plan, gestion des écarts et double vérification.
5. **v0.6.x — Échanges et backend privé** : identité forte, rôles, autorisations d’accès, stockage chiffré, accusés de réception prouvés, journal serveur horodaté, non-répudiation, mode dégradé défini. **Phase conditionnée à l’avis de la sécurité ferroviaire et cybersécurité**.
6. **v1.0 — Référentiel validé** : validation officielle des processus et du référentiel réglementaire, essais terrain supervisés, homologation selon règles de l’exploitant.
7. **Intégration Journal de chantier** : API contractuelle et droits réutilisant JDC, tests de non-régression, déploiement séparé, jamais avant validation.

Aucun outil grand public ne doit être présenté comme une dépêche officielle ou comme une attestation réglementaire tant que les autorités concernées n’ont pas approuvé le dispositif.
